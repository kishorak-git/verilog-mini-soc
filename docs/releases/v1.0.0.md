# Verilog-Mini-SoC v1.0.0

## Summary

This is the first verified release of a simulation-based 32-bit Mini System-on-Chip in Verilog. It includes a shared memory-mapped bus and address decoder, RAM, GPIO, timer, UART, and SPI master. The release includes standalone verification testbenches, full-system integration verification, Windows and Ubuntu automation, Icarus Verilog simulation, Yosys generic synthesis reporting, and technical documentation.

## Included

- Complete Mini SoC RTL integration.
- Shared 32-bit memory-mapped bus with an explicit `re` read strobe and existing `we` write strobe.
- 1024-word 32-bit RAM.
- Memory-mapped GPIO output and input registers.
- Configurable timer control, counter, and period registers.
- UART transmit and receive paths with a two-flop RX synchronizer, stop-bit framing-error detection, sticky receive-ready, transmit-done, and framing-error status.
- SPI master with sticky transfer-done status.
- GPIO, RAM, Timer, UART, SPI, and full-system testbenches.
- Automated Windows PowerShell compile and regression scripts plus a Linux regression runner.
- Architecture documentation and Mermaid diagrams.
- Consolidated and individual simulation reports.
- GitHub Actions Windows and Ubuntu regression workflows.
- Ubuntu CI regression and Yosys synthesis verified for commit `36176cd01ccef760fae02e0344e45c80d30f0757`.

## Icarus and Yosys

Icarus Verilog compiled and ran all six suites. Yosys 0.71 generic synthesis produced:

| Block | Generic Yosys cells |
|---|---:|
| RAM | 66,701 |
| GPIO | 177 |
| Timer | 553 |
| UART | 643 |
| SPI | 413 |
| Mini SoC total | 68,761 |

These are generic Yosys synthesis cell counts, not FPGA LUT, flip-flop, or DSP utilization figures. In this generic flow, the 4 KB RAM is represented with 32,768 memory-state flip-flops and accounts for approximately 97% of the top-level count.

## Limitations

This release has no CPU and is not a physical hardware or FPGA implementation. It has not been validated on physical FPGA hardware or against external silicon. Validation is simulation-only.
