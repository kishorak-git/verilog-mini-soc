# Verilog-Mini-SoC v1.0.0

## Summary

This is the first verified release of a simulation-based 32-bit Mini System-on-Chip in Verilog. It includes a shared memory-mapped bus, RAM, GPIO, timer, UART, SPI master, standalone verification testbenches, full-system integration verification, Windows PowerShell automation, and technical documentation.

## Included

- Complete Mini SoC RTL integration.
- 1024-word 32-bit RAM.
- Memory-mapped GPIO output and input registers.
- Configurable timer control, counter, and period registers.
- UART transmit and receive paths with sticky receive-ready and transmit-done status.
- SPI master with sticky transfer-done status.
- GPIO, RAM, Timer, UART, SPI, and full-system testbenches.
- Automated Windows PowerShell compile and regression scripts.
- Architecture documentation and Mermaid diagrams.
- Consolidated and individual simulation reports.
- GitHub Actions Windows regression workflow.

## Verification

The v1.0.0 implementation has a verified local result of 35 checks and zero errors across six suites:

| Suite | Checks | Errors |
|---|---:|---:|

| UART | 5 | 0 |

This release has not introduced hardware validation or physical FPGA claims. Validation is simulation-only.
